# TypeMeter – Typing Speed Test

TypeMeter is a simple and interactive Typing Speed Test web app built using HTML, CSS, and JavaScript.  
It measures your WPM, CPM, accuracy, and mistakes in real time, and automatically stops the timer when the paragraph is typed correctly.

##  Features
- Real-time WPM, CPM, accuracy, and mistake tracking
- Auto-stop when the full paragraph is typed correctly
- Random paragraph generation
- Light & Dark mode toggle
- Character-by-character correctness highlighting
- Smooth progress bar timer
- Clean, modern, responsive UI

##  Tech Stack
- HTML
- CSS
- JavaScript

##  How to Use
1. Open `index.html` (or your HTML file) in any browser.
2. Start typing — the timer begins automatically.
3. View your speed and accuracy when time ends or when you finish typing.
